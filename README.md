# 株モン

株モンは、株式をテーマにした育成・放置ゲームの試作アプリです。

スマホ縦画面向けのWebアプリとして作成しています。v0.1では本物の株価APIは使わず、仮の終値変化と固定モンスターデータで、ガチャ、育成、放置報酬、図鑑、チーム、マーケット購入、100株売却を動かします。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで以下を開きます。

```text
http://localhost:3000
```
