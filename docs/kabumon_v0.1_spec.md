# 株モン v0.1 仕様書

## 目的

株モン v0.1 は、株式をテーマにした育成・放置ゲームの最小試作版です。

実在の株価APIや課金機能は使わず、仮の終値変化と固定モンスターデータで、以下の基本体験を完成させます。

```text
アプリを開く
↓
放置報酬を受け取る
↓
ガチャで株モンを入手
↓
被ったら持ち株が100株増える
↓
チームに編成する
↓
仮の市場エネルギーで自動成長する
↓
図鑑に登録される
↓
リロードしても保存される
```

## 確定方針

- スマホ縦画面向けWebアプリとして開始する
- 技術想定は Next.js、TypeScript、Tailwind CSS
- v0.1では本物の株価APIを使わない
- v0.1では課金・広告を入れない
- 保存は localStorage を使う
- モンスターはあらかじめ用意した固定データを使う
- モンスター画像は実装フェーズで生成する
- 実在企業ロゴ、商標、製品名は画像に入れない
- 企業名は仮名運用にする
- UIは最初の参考画像をホーム画面リファレンスにする
- 放置報酬は最大12時間分まで蓄積する
- 初期チームは3体編成にする

## 通貨

### カブコイン

用途:

- ガチャ
- マーケット購入

### 配当コイン

用途:

- 育成
- 強化

v0.1ではジェム系の有料通貨は作りません。

| 名前 | 銘柄コード | 表示企業名 | レア度 | 属性 | 役割 |
|---|---:|---|---|---|---|
| トヨドラ | 7203 | 自動車メーカーA | SSR | メカ | 安定成長型 |
| ニンテンドラ | 7974 | ゲーム企業A | SR | 遊び | 変化成長型 |
| ソニックレオ | 6758 | クリエイティブ企業A | SSR | 光・音 | 特殊高速型 |
| バンクゴーレム | 8306 | 銀行グループA | SR | 鉄壁 | 配当防御型 |
| チップサンダー | 6920 | 半導体装置企業A | SSR | 雷 | 高変動型 |

## 画像生成ルール

実装タイミングでモンスター画像を生成します。

- メイン画像: 1024x1024 PNG
- 小アイコン: 256x256 PNG
- できれば背景透過
- 実在企業ロゴを入れない
- 実在製品名やブランド名を入れない
- 企業の特徴は業種イメージとして抽象化する

例: トヨドラ

- OK: 白銀のメカドラゴン、タイヤ風パーツ、エンジン風コア、青いエネルギー
- NG: 実在企業ロゴ、実在車種名、実在エンブレム、特定メーカーに寄せすぎた意匠

## 画面

### ホーム

参考画像に近い構成にします。

- ヘッダー
- プレイヤー名
- カブコイン
- 配当コイン
- 今日の市場エネルギー
- 今日のテーマ
- 相棒モンスター
- モンスター詳細
- 本日の成長結果
- チーム効果
- ステータス
- ガチャボタン
- 育成ボタン
- 下部ナビ

### ガチャ

- カブコインを消費して抽選する
- 初入手なら図鑑登録する
- 被りなら持ち株を100株増やす
- レア度はゲーム内演出であり、投資価値とは無関係とする

### 育成

- 配当コインを使って手動育成する
- 仮の終値変化による成長結果を表示する
- 上昇日、下落日、横ばいで伸びるステータスを変える

### チーム

- v0.1では3体編成
- 編成中モンスターが放置報酬に影響する
- チーム効果は簡易表示から始める

### 図鑑

- 初期5体の所持状況を表示する
- 未所持、所持済み、持ち株数、属性、レア度を確認できる

### マーケット

- v0.1では仮画面または簡易購入まで
- 詳細な売買機能はv0.2以降に回す

## 放置報酬

### 基本仕様

- 最終ログイン時刻を保存する
- 次回起動時に経過時間を計算する
- 最大12時間分まで報酬を蓄積する
- チーム編成、持ち株数、レベル、配当力で報酬量が変わる
- 受け取りボタンでまとめて獲得する

### 報酬対象

- カブコイン
- 配当コイン
- 経験値

### 計算イメージ

```ts
offlineReward =
  baseRatePerHour
  * hours
  * sharesBonus
  * levelBonus
  * teamBonus;
```

## 仮の市場エネルギー

v0.1では実データを使わず、ログイン時または育成時に仮の終値変化を生成します。

| 変化率 | 成長方向 |
|---:|---|
| +3%以上 | 経験値大、攻撃、成長力 |
| +1%から+3% | 経験値、攻撃 |
| -1%から+1% | 安定成長、運、配当 |
| -3%から-1% | 防御、HP |
| -3%以下 | 防御、HP、逆境ゲージ |

下落してもプレイヤーが損をするだけの設計にはせず、何かしら育つようにします。

## 保存データ

localStorageに保存する項目です。

- 所持モンスター
- 持ち株数
- レベル
- 経験値
- ステータス
- 所持カブコイン
- 所持配当コイン
- 最終ログイン時刻
- 図鑑解放状況
- ロック状態
- 成長ログ
- チーム編成

## 注意文

アプリ内に以下の注意文を表示します。

```text
このアプリは株価や企業を題材にしたゲームです。
特定の銘柄の売買をすすめるものではありません。
ゲーム内のレア度・能力・価格・配当・利回りは、実際の企業価値や投資判断を示すものではありません。
```
